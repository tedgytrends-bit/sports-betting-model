BEHIND THE NUMBERS

How it works.

Every number shown is taken from a committed GitHub file. The website displays results; it does not train or re-run the Python models.

01 / THE FOUNDATION

Existing Python models

GitHub Actions and Python generate predictions. The static website reads committed snapshots, so using the website does not use paid APIs or rerun a model.

02 / THE ADJUSTMENT

Baseline and Injury views

The primary board includes the baseline and injury-adjusted forecasts. Experimental Efficiency and Combined variants are available in each matchup breakdown with clear research labeling.

03 / THE AUDIT TRAIL

Archived model and market timestamps

Model snapshots and Bovada market archives carry different timestamps. Archived line ingestion is not the same as screenshot capture time. A separate updated model run will only be shown when explicitly available.

04 / THE SCORECARD

Week 8 public record, separated from research

The full 14-game Week 8 comparison is shown first to match our Streamlit results, and is clearly labeled research. Switch to the original 12 published picks to see the strict public prospective record. Weeks 1–7 are excluded.
